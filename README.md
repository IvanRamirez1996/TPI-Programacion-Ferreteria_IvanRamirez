# 🛒 Proyecto Integrador (TPI) - Sistema de Gestión de Ferretería

Este repositorio contiene la primera parte del Proyecto Integrador correspondiente al desarrollo de un sistema modular en Python para la gestión de una ferretería. El proyecto incluye el **código fuente**, la **documentación formal en formato PDF** y la **defensa en video**.

* 🔗 **Enlace del Repositorio:** [TPI-Programacion-Ferreteria_IvanRamirez](https://github.com/IvanRamirez1996/TPI-Programacion-Ferreteria_IvanRamirez)
* 🎥 **Enlace de Video:** [Enlace al video de la presentación](https://drive.google.com/file/d/19Fa3-DVEK7_VB7lGvBCtpQrLai-UnXR3/view?usp=drive_link)

---

## 📂 Contenido del Repositorio

1. **Código Fuente (`Ivan_Ramirez_P1/`):** Desarrollado de forma modular en Python, estructurado de la siguiente manera:
   * `ferreteria/interfaz/`: Gestión de menús e interacción con el usuario.
   * `ferreteria/operaciones/`: Módulos de carga de datos, consultas y control de stock.
   * `ferreteria/utilidades/`: Funciones de validación de entradas.
   * `main.py`: Script principal para la ejecución de la aplicación.
   
2. **Informe Explicativo (`Informe_TPI_Ramirez_Ivan.pdf`):** Documento técnico detallado que acompaña el desarrollo, la arquitectura y las decisiones de diseño del sistema.

3. **Demostración en Video:** Registro audiovisual de la presentación y funcionamiento del software.

---
